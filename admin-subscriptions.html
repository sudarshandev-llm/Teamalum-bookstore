Book Content

Publish the chapters that licensed readers can open.

Each chapter is stored as two rows so the database can keep the free preview separate from the paid text: a Preview row (is_free_preview = true) that anybody may read, and a Full row (is_free_preview = false) that only a reader with an active license can read. Add the preview row first, then the full row for the same chapter number.
